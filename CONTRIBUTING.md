# Contributing

Test results from real FreeCAD, Fusion and slicers, corrections to the paper, prior art I missed, other CAD exporters and pull requests are welcome.

- Open an issue first for anything big.
- By contributing you agree your contribution is licensed under the same terms as the part it changes: text and figures under [CC BY-SA 4.0](LICENSE.md), code under the [PolyForm Noncommercial License 1.0.0](LICENSE-CODE.md), with the Required Notice `Copyright Matthew Armstrong (https://github.com/The-Dorkknight)` kept in every source file header.
- Only contribute what you have the right to contribute.
- Edit `paper/paper.md`, never `README.md` (it is generated). Then run `python3 tools/build_paper.py` and `python3 tools/make_readme.py`, and `python3 tests/check_repo.py`.
- Contributors are credited in the next version of the paper.
